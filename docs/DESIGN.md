# 排版与视觉

阅读页的字体、节奏、颜色，以及为什么这样定。

## 阅读排版

整页**只用一套衬线家族**（俪宋 LiSong Pro），标题和正文靠字号分层次——这是杂志的做法，不是"标题一种字体、正文另一种"。

正文基线：**18px / 行高 1.9 / 字距 +.02em / measure 32rem**；标题 1.76em 并 `text-wrap: balance`。

> 改排版模板**不会自动更新旧文章**：阅读页是渲染时把 CSS 一起写进 `content.html` 的。
> 改完样式跑 `node scripts/rerender.mjs` 重渲染一遍（只读本地，不联网、不碰 Obsidian）。

站点原文（微信）的 inline style 会做一次**排版归一**（`lib/sanitize.js`）：

| 处理 | 原因 |
|---|---|
| 去掉 `font-family` / `line-height` / `letter-spacing` | 各号排版不同，放行就像从三个 App 里截出来的 |
| `font-size` 只保留 15–40px | 太小的交给正文，太夸张的交给标题层级 |
| 保留颜色 / 对齐 / 间距 / 边框 | 这些是排版意图，不该被抹掉 |

## 标签

详情页标题下方是一条标签带：点 `+ 标签` 输入回车即可加，点 `×` 删。改完立刻落盘；
**已投影的会顺手重投一次**，Obsidian 里的文件和索引跟着变（vault 不可用时只存本地，不会因此失败）。


## 视觉

跟随 `dsh-panel-kit` 的《自建面板设计规范》：同纸、同墨、同信号色、同刊头。

| 层 | 日版 | 夜版 |
|---|---|---|
| 纸 | `#faf6ee` | `var(--dsw-alias-bg-base, #151517)`（跟随宿主） |
| 卡片（阅读页、输入框、iframe） | `#fffcf6` | `#232324` |
| 第二纸（图版占位、阅读区底） | `#f1eadc` | `#1b1c1e` |
| 第三纸（悬停、选中） | `#f5eee2` | `#2c2c2e` |
| 墨（主 / 次 / 弱） | `#1b1813` / `#4b453a` / `#7f7666` | `#f9fafb` / `#cfd3d6` / `#81858c` |
| 发丝线 / 署名线 | `.14` / `.62` | `.06` / `.12` |
| 信号色（唯一点缀） | `#a8452f` | `#ff6363` |

**主题切换点**：`@media (prefers-color-scheme: dark)`。阅读页（iframe 内）与面板各自独立跟随系统；
宿主若以后提供主题属性，两处一起换成同一选择器即可。

**控制件几何**：`--pk-*` 拷贝自 `panel-kit/panel-kit.css`，用 `@panel-kit:begin/end` 标出边界。
`panel-kit/check.mjs` 目前还没把这块面板登记进 `panels.json`，所以 `--fix` 不会覆盖它；
登记之后记得同步。

排版上的几条取舍：

- 一屏只有一个实心按钮（「收藏」），其余都是描边或安静按钮。
- 列表里不标「本地」——那是默认状态，标出来只是噪音；只标「视频」和「已同步」。
- 阅读页标题用衬线（`Iowan Old Style / Songti SC`），正文用系统 UI 字体 17px/1.78，measure 34rem；
  标题下方一条署名线，是这块面板的版面签名。
- 图片整列竖排、圆角统一 8，与控件同一套圆角；首图不 lazy。
